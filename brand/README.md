# AU-Van brand

The mark is a serif "A" with the amber dot from the AU·Van wordmark, drawn by
hand after Fraunces so it needs no font. Navy `#1b2566`, paper `#f6f3ec`, amber
`#d99a2b`, ink `#14172b`; Fraunces, Instrument Sans and JetBrains Mono.

`logo.svg` is the master and `web/public/favicon.svg` a copy. The PNGs are
Playwright screenshots of it on a navy page; the LINE profile keeps the mark at
560 of 640 px so the circular crop misses it. `rich-menu.png` comes from
`scripts/line/rich-menu.html` (see `scripts/line/README.md`).
